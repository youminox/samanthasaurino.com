# Samantha Saurino — Sitio Web Oficial (`samanthasaurino.com`)

Sitio web oficial de **Samantha Saurino**, emprendedora peruana, fundadora de **Belle 364** ([belle364.com](https://belle364.com/)) y creadora de contenido digital.

## Stack Tecnológico
- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Estilos:** Tailwind CSS v4 + `@tailwindcss/typography`
- **Contenido:** +760 artículos migrados desde WordPress con imágenes optimizadas en formato WebP y redirecciones 301 permanentes.
